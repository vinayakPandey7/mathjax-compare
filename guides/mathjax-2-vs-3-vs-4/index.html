MathJax 2 vs 3 vs 4: Differences Explained with Live Examples

MathJax 3 is a complete rewrite of MathJax 2, and MathJax 4 builds on version 3 with new fonts and line breaking. This page compares all three versions in one table, then shows the differences you can see for yourself in the live preview.

MathJax 2 vs MathJax 3

This is the big jump. MathJax 3 was rewritten in TypeScript and renders much faster than MathJax 2, but almost everything you write to set it up changes:

  • The script URL and the configuration format are different.
  • The MathJax.Hub API is gone, so code that re-renders math needs updating.
  • HTML-CSS and NativeMML output were removed; CommonHTML and SVG remain.
  • Automatic line breaking was dropped, so long equations overflow instead of wrapping.
  • \color now behaves like real LaTeX, which can recolour more than you expect.

The MathJax 2 to 3 migration guide covers each change with before-and-after code.

MathJax 3 vs MathJax 4

MathJax 4 keeps the version 3 configuration and API, so most sites can upgrade by changing the script URL. The visible differences are:

  • Fonts: the new default font covers many more characters, and glyph shapes and spacing look slightly different.
  • Line breaking: long inline math wraps at top-level operators such as + and =, but not inside brackets like (a + b + c)^2.
  • File paths: there is no es5/ folder in the CDN URL.
  • Accessibility: speech and keyboard exploration of equations are improved.

Which version should you use?

  • New site: use MathJax 4.
  • Already on MathJax 3: upgrading to 4 is usually a URL change. Check that the new font and line breaking look right for your content.
  • Still on MathJax 2: plan a migration. MathJax 2 still works, but it is no longer developed and is slower than 3 and 4.
